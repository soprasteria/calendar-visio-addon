# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-28

### Added
- Initial release
- "Create Visio meeting" button injected into the Nextcloud Calendar event editor (EditFull and EditSimple views)
- OAuth2 client-credentials flow against the Meet External API (`/external-api/v1.0/application/token/` + `/external-api/v1.0/rooms/`)
- Admin settings panel (Nextcloud Settings → Administration → Calendar Visio Add-on)
- French translations (`l10n/fr.json`, `l10n/fr.js`)
